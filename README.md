# Corredor web (`tic-web`)

The Corredor frontend: TanStack Start (React 19) + TanStack Router, Query and Table, Tailwind v4, built with rsbuild. It talks to [`tic-api`](../tic-api). Product and screen plan: `docs/FRONTEND.md`.

## Run it

```sh
bun install
cp .env.example .env          # first time only
bun --bun run dev             # http://localhost:8080
```

It needs `tic-api` on `PUBLIC_API_URL` (default `http://localhost:3000`). Start that first:

```sh
cd ../tic-api && bun run db:up && bun run db:migrate && bun run db:seed && bun run dev
```

No API? Set `PUBLIC_USE_FIXTURES=true` in `.env` to read `src/fixtures/` instead. Reading works; approve, pay and edit need the real API.

## Where things are

| Path | What |
|---|---|
| `src/routes/` | File routes: `index` (payouts inbox + as-of slider), `payouts.$id` (detail), `ledger`, `audit` |
| `src/lib/api.ts` | The only code that calls the API (query options and mutations, with the fixtures switch) |
| `src/lib/contracts.ts` | **Copy** of `tic-api/src/contracts.ts`. Don't edit it here (see below) |
| `src/lib/search.ts` | The `?asOf=` search param (zod), the demo date and the slider's jump dates |
| `src/components/` | Shared pieces: `StatusPill`, `Money`, `RouteChip`, `CountryFlag`, `SimBadge`, `AsOfSlider`, `RerouteToast`, `PayoutTable` |
| `src/fixtures/` | Generated by the real rules engine. Refresh with `cd ../tic-api && bun run fixtures` |

## Keeping in sync with the API

Whenever `tic-api/src/contracts.ts` changes, copy it over and refresh the fixtures:

```sh
cp ../tic-api/src/contracts.ts src/lib/contracts.ts
(cd ../tic-api && bun run fixtures)
```

## Checks

```sh
bunx tsc --noEmit             # types
bun --bun run check           # Biome lint + format (use `bunx biome check --write` to fix)
bun --bun run build           # production build (also regenerates src/routeTree.gen.ts)
```
